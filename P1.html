넘플초

🎮 게임 소개

넘플초 (NUMPPLE CHO) = 넘버(NUMBER) + 사과(APPLE) + 초(CHO)


📋 게임 규칙

  • 두 플레이어가 주어진 숫자와 연산기호를 이용하여 목표 숫자에 가장 가까운 결과를 만드는 게임입니다.
  • 숫자 카드 4장과 연산기호 3장(+, -)을 사용합니다.
  • 수식의 결과가 목표 숫자에 더 가까운 플레이어가 10점을 받습니다.
  • 두 플레이어의 이름을 입력하세요. 입력하지 않으면 플레이어1, 플레이어2로 표시됩니다.
  • 목표 숫자를 설정하고 게임을 시작합니다.
  • 모든 카드를 사용하지 않아도 됩니다.
  • 각 플레이어는 독립적인 카드 세트를 가집니다.
  • 10라운드 게임으로 진행됩니다.

🎮 Game Overview

NUMPPLE CHO = NUMBER + APPLE + CHO

📋 Game Rules

  • Two players use given numbers and operators to create expressions as close as possible to the target number.
  • Use 4 number cards and 3 operator cards (+, -).
  • The player whose expression is closer to the target number receives 10 points.
  • Please enter the names of both players. If left blank, they will be named Player 1 and Player 2.
  • Set the target number and start the game.
  • You don't have to use all the cards.
  • Each player has an independent set of cards.
  • The game proceeds for 10 rounds.
