## 넘플 (Numpple) 

**넘플(Numpple)**은 **넘버(Number)**와 **사과(Apple)**을 결합한 이름입니다.  
** 넘플은 넘즐의 스핀오프게임으로 npc 와 대결하는 넘즐과 다르게 두 사용자가 대결합니다.
Numpple is a name that combines Number and Apple.
Numpple is a spin-off game of Numzzle, and unlike Numzzle where you compete against NPCs, two users compete against each other.

## 🎮 게임 개요 | Game Overview

넘플은 수학 감각과 창의력을 발휘해야 하는 재미있는 계산 게임입니다.  
한 라운드마다 주어진 카드로 수식을 만들고,  
**목표 숫자에 가장 가까운 값**을 만든 사람이 점수를 얻습니다.

 Numpple is a fun and strategic math game  
 that challenges your sense of numbers and creativity.  
 Each round, you build an expression using cards to get  
 as close as possible to the **target number**.

---

## 📋 공통 게임 규칙 | Common Game Rules

- 목표 숫자를 설정하고 게임을 시작합니다.  
 Set a target number and start the game.

- 숫자 카드와 연산 카드가 랜덤으로 주어집니다.  
 You receive random number and operator cards.

- 연산 카드에는 +, −, ×, ÷ 등이 포함됩니다.  
 Operators include +, −, ×, ÷ 

- 주어진 카드로 수식을 만들어 목표 숫자에 가장 가까운 값을 제출합니다.  
 Build an expression using the cards to get as close as possible to the target number.

- 모든 카드를 사용하지 않아도 되며 숫자카드 1장만 사용해도 됩니다.
 You don’t have to use all cards, and you can use just one number card.​​​​​​​​​​​​​​​

- 두 사람이 대결하며, 수식 결과가 목표 숫자에 더 가까운 사람이 10점을 얻습니다.
Two people compete against each other, and the person whose formula result is closer to the target value gets the point.​​​​​​​​​​​​​​​​

- 실수했을 경우 초기화 버튼으로 수식을 다시 만들 수 있습니다.  
 If you make a mistake, use the reset button to start your expression over.

- 총 10라운드 동안 플레이하며 **누적 점수**로 승패를 결정합니다.  
   Play 10 rounds. The player with the highest total score wins.

## 🧩 버전별 차이점 | Version Differences

넘플 시리즈는 총 세 가지 버전으로 구성되어 있으며, 각 버전은 규칙과 난이도에 따라 차이가 있습니다.  
The Numpple series includes three versions, each with different rules and difficulty levels.

**넘플초**  
가장 쉬운 버전으로, 1부터 20까지의 숫자카드가 제공되며 숫자 카드를 이어붙일 수 없습니다.  
연산 기호는 +, − 만 제공됩니다.  
**Numpple Cho** 
the easy version.  Only + and − are allowed.  
Number cards from 1 to 20 are provided, and you cannot connect number cards together.​​​​​​​​​​​​​​​​

---

**넘플잼 (Numzzle Jam)**  
연산 기호에 +, -, ×가  있습니다.  
숫자 카드는 0~9까지의 숫자 카드를 이어붙여서 여러 자리 숫자를 만들 수 있습니다.  
**Numpple jam**  
The operation symbols available are +, -, and ×.
Number cards can be connected together using digit cards from 0 to 9 to create multi-digit numbers.​​​​​​​​​​​​​​​​

---

**넘플 (Numpple)**  
+, −, ×, ÷ 기호를 사용할 수 있고,  
숫자카드를 이어붙여서 여러 자리 숫자를 만들 수 있습니다.
**Numpple**  
It uses +, −, ×, ÷ operators and   
Card combinations are allowed.

---

**넘플업 (Numpple Up)**는 가장 고급 버전으로,  
+, −, ×, ÷에 더해 √(루트)도 사용할 수 있으며,전략적인 점수 계산이 필수입니다.  
난이도는 높지만 수학적 사고력과 논리력을 최대한 자극합니다.  
향후 개발 예정입니다.
**Numpple Up** is the most advanced version.  
It includes the √ (square root) operator and requires strategic score management.  
It is designed to challenge both mathematical thinking and creativity at the highest level.
This is planned for future development.​​​​​​​​​​​​​​​​

---

각 버전은 난이도뿐 아니라 **연산 도구의 범위, 카드 사용 방식, 게임 자유도**에서도 차이를 보이며,  
학습 단계나 실력에 따라 선택해 즐길 수 있도록 설계되었습니다.  
Each version differs not only in difficulty, but also in available operations, card usage rules, and overall game flexibility.    
allowing players to choose based on their skill and learning level.---
