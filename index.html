넘플

숫자 카드와 연산기호 카드로 수식을 만드세요.

넘플 (NUMZZLE)=넘버(NUMBER) + 사과(APPLE)

📋 게임 규칙

  • 두 사용자가 이름을 적습니다.목표 숫자를 설정하고 게임을 시작합니다.
  • 라운드마다 서로 다른 숫자 카드와 연산 카드가 랜덤으로 주어집니다.
  • 주어진 카드로 수식을 만들어 목표 숫자에 가장 가까운 값을 제출합니다.
  • 실수했을 경우 초기화 버튼으로 수식을 다시 만들 수 있습니다.
  • 결과값이 서로 다를 경우, 목표 숫자에 가까운 사람이 10점을 받습니다.
  • 총 10라운드를 진행하며, 누적 점수가 더 높은 쪽이 승리합니다!

Create an equation using the given cards

NUMPPle = NUMBER + APPLE

📋 Game Rules

  • Set a target number and start the game.
  • Each round, different number cards and operation cards are randomly given.
  • Create an equation using the given cards to submit a value closest to the target number.
  • If you make a mistake, you can use the reset button to recreate your equation.
  • When the results are different, the person closer to the target number receives 10 points.
  • Play a total of 10 rounds, and whoever has the higher cumulative score wins!
